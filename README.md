# A/B-тест таргетинга: снижение стоимости лида в рекламной кампании

Проверка гипотезы о более узкой целевой аудитории для рекламной кампании
**корпоративного страхования** (регион Саудовская Аравия, ОАЭ) и оценка эффекта
на CR и CPL с помощью z-теста для пропорций.

## Задача

Снизить стоимость лида (CPL), не потеряв в качестве трафика, за счёт более точного
таргетинга рекламной кампании — вместо того, чтобы наращивать бюджет или менять креативы.

## Данные

- Источник: рекламные кабинеты Google Ads и Meta Ads, реальная кампания клиента
- Период: указан в дашборде (раздел «Дашборд» ниже)
- Данные анонимизированы под NDA: реальные ID посетителей заменены на сквозной номер строки
- Файл `data/ab_test_data.csv`: 2075 строк, одна строка — один уникальный посетитель

| Колонка | Описание |
|---|---|
| `id` | сквозной номер строки (анонимизированный идентификатор) |
| `group` | `control` / `test` |
| `converted` | 1, если посетитель оставил заявку (стал лидом), иначе 0 |

## Методология

1. **Гипотеза.** Клиент считал целевой аудиторией мужчин и женщин 25–55 лет. По ходу
   кампании возникла гипотеза, что решение о покупке корпоративной страховки в этом
   регионе принимают **C-level и руководители направлений** — обычно мужчины от 35 лет.
   Более узкий и релевантный таргетинг должен поднять CR и, как следствие, снизить CPL.

2. **Планирование выборки.** До запуска теста рассчитан необходимый объём трафика на
   группу: по историческому CR (2.35%) и ожидаемому эффекту (удвоение CR), при мощности
   80% и alpha 0.05 — через power analysis для пропорций (arcsine-преобразование,
   Cohen's h).

3. **Дизайн эксперимента:**
   - **Гипотеза:** узкий таргетинг (C-level, мужчины 35+) даёт более высокий CR, чем
     широкий (М/Ж, 25–55)
   - **Единица рандомизации:** уникальный посетитель рекламы
   - **Метрика:** конверсия трафика в лида (`converted`, бинарная — 0/1)
   - **Группы и их объём:**

     | | Control (широкий таргетинг) | Test (C-level, 35+) |
     |---|---|---|
     | Трафик (уникальные посетители) | 1 212 | 863 |
     | Лиды (конверсии) | 29 | 39 |
     | Бюджет (зафиксирован заранее, откручен полностью) | $3 000 | $2 000 |

4. **Статистический тест.** Двусторонний z-тест для двух независимых пропорций —
   метрика бинарная, группы большие, единица рандомизации совпадает с единицей
   наблюдения.

5. **Расчёт производной метрики CPL.** Бюджет в обеих группах зафиксирован заранее и
   отработан полностью — то есть является константой. Значит, статистическая значимость
   разницы в CR напрямую переносится на CPL без отдельного теста (подробное обоснование —
   в ноутбуке, раздел 4).

6. **Визуализация и выводы.** Сравнение CR и CPL по группам с доверительными
   интервалами — см. `notebook/analysis.ipynb`.

## Результаты

- CR вырос с 2.39% до 4.52% (+89% относительного uplift), z-тест: **p = 0.007** — значимо
- CPL снизился с $103 до $51 (**-50%**)
- Тест собрал немного меньше трафика, чем планировалось (863 вместо 940) — реальный
  эффект оказался достаточно сильным, чтобы мощности всё равно хватило

Полный разбор с графиками — в `notebook/analysis.ipynb`.
