# A/B-тест: сужение таргетинга снижает CPL на 50%

**Индустрия:** корпоративное страхование (B2B)
**Регион:** Саудовская Аравия, ОАЭ
**Платформы:** Google Ads, Meta Ads

## Цель

Снизить стоимость лида (CPL), не теряя в объёме, за счёт более точного таргетинга.

## Гипотеза

Клиент считал целевой аудиторией мужчин и женщин 25–55 лет. По ходу кампании возникла гипотеза,
что решение о покупке корпоративной страховки в этом регионе принимают **C-level и руководители
направлений** — обычно мужчины от 35 лет. Сузили таргетинг под этот профиль и ожидали удвоения CR.

## Дизайн эксперимента

| | Control | Test |
|---|---|---|
| Таргетинг | Широкий (М/Ж, 25–55) | Узкий (C-level, М, 35+) |
| Трафик (уникальные лиды) | 1 212 | 863 |
| Конверсии | 29 | 39 |
| Бюджет (фиксирован заранее, откручен полностью) | $3 000 | $2 000 |

Единица наблюдения — уникальный лид. Метрика — конверсия в лид (0/1).

## Результат

- **CR:** 2.39% → 4.52% (+89%, z-тест, p = 0.007) — значимо
- **CPL:** $103 → $51 (-50%) — бюджет был фиксирован заранее в обеих группах, поэтому снижение
  CPL следует напрямую из значимого роста CR, без отдельного теста

Подробный расчёт, код и графики — в [`notebook/analysis.ipynb`](notebook/analysis.ipynb).
